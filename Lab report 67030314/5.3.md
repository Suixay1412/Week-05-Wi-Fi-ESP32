## 3. คำถามท้ายการทดลอง (Post-Lab Questions)

1. **Association ID (AID)** คืออะไร มีบทบาทอย่างไรใน Phase 3 และส่งคืนมาในโครงสร้างข้อมูลตัวแปรใด?
ตอบ AID คือหมายเลขระบุตัวตนประจำ Station ที่ AP จัดสรรให้เมื่อทำการผูกสัมพันธ์ระดับ Link Layer สำเร็จ มีบทบาทใช้จัดคิวรับส่งแพ็กเกจและจัดการโหมดประหยัดพลังงาน (Power Save Mode) บน AP โดยส่งคืนมาผ่านตัวแปรสมาชิก `aid` ในโครงสร้างข้อมูล `wifi_event_sta_connected_t`

2. เหตุใดการเชื่อมต่อ Wi-Fi ความปลอดภัยแบบ WPA2-PSK จึงสามารถผ่าน Phase 2 (Authentication) และ Phase 3 (Association) จนเกิด Event `WIFI_EVENT_STA_CONNECTED` ได้สำเร็จ แม้ผู้ใช้จะป้อนรหัสผ่าน (Password) ผิด?
ตอบ เพราะมาตรฐาน IEEE 802.11 ใน Phase 2 (Authentication) และ Phase 3 (Association) เป็นกระบวนการ Open System ที่ตกลงเฉพาะคุณสมบัติช่องสัญญาณระดับ Link Layer โดยยังไม่มีการตรวจสอบรหัสผ่านจริง รหัสผ่านจะถูกนำไปพิสูจน์ทราบผ่านการคำนวณ MIC ใน Phase 4 (4-Way Handshake) ถัดไป

3. หาก Router มีการตั้งค่า **MAC Address Filtering** (อนุญาตเฉพาะ MAC ที่ลงทะเบียน) ESP32 จะล้มเหลวในเฟสใด และจะส่ง Disconnect Reason Code ใดออกมา?
ตอบ จะล้มเหลวใน **Phase 2 (Authentication Phase)** หรือ **Phase 3 (Association Phase)** เนื่องจาก AP ปฏิเสธการเชื่อมต่อ และจะส่ง Disconnect Reason Code เช่น `1` / `202` (`WIFI_REASON_AUTH_FAIL`) หรือ `3` / `203` (`WIFI_REASON_ASSOC_FAIL`) ออกมา

4. สรุปความแตกต่างสำคัญระหว่างจุดสิ้นสุดของ **Phase 3 (Link-Layer Connected)** กับจุดสิ้นสุดของ **Phase 5 (IP Address Assigned)**
ตอบ จุดสิ้นสุด Phase 3 ยืนยันเฉพาะการเชื่อมต่อสัญญาณวิทยุและผูกสัมพันธ์ฮาร์ดแวร์ระดับ Layer 2 (Data Link) สำเร็จ แต่ยังส่งข้อมูลผ่านโปรโตคอล IP ไม่ได้ ส่วนจุดสิ้นสุด Phase 5 ยืนยันการตกลงคีย์ความปลอดภัยและได้รับหมายเลข IP Address ระดับ Layer 3 (Network Layer) จาก DHCP Server เรียบร้อยแล้ว พร้อมส่งข้อมูลผ่านอินเทอร์เน็ตได้จริง
